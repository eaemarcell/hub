
# AMT-HUB

O **AMT-HUB** é uma suíte unificada para gestão de infraestrutura da AMT, integrando os sistemas SIGHE, pfViewer e PassGen de forma prática e centralizada.

O sistema permite a navegação unificada entre ferramentas internas, gestão de escalas de sobreaviso e controle de horas extras, otimizando os processos operacionais da equipe.

## Objetivo

Fornecer um ambiente simples e centralizado para:

* Centralização de sistemas internos
* Gestão e controle de horas extras (SIGHE)
* Acompanhamento de escalas de sobreaviso
* Visualização de regras de firewall (pfViewer)
* Geração de senhas seguras (PassGen)

## Infraestrutura

A plataforma foi desenvolvida sobre uma arquitetura leve containerizada, garantindo alta disponibilidade e facilidade na manutenção dos serviços.
